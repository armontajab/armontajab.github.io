ALIREZA MONTAJAB — PERSONAL WEBSITE
Theme: indigo

This folder is a complete, ready-to-publish copy of the site.
The ONLY file that differs between the four theme folders is
style.css. Every HTML page is identical.

TO SWITCH THEMES LATER
  Copy style.css from the theme folder you prefer over the
  style.css in your armontajab.github.io folder, then commit
  and push. Nothing else changes.

INCLUDED
  16 HTML pages, style.css, motion.js, img/, cv.pdf

TO PUBLISH
  Replace the contents of your armontajab.github.io folder with
  these files (keep the hidden .git folder), then in GitHub
  Desktop: write a summary, Commit to main, Push origin.
