ALIREZA MONTAJAB - PERSONAL WEBSITE
Colour: pine (pine green, the current colour)

This folder is a complete, ready to publish copy of the site.
All four colour folders contain identical HTML. Only style.css
differs, so whichever you pick, nothing else changes.

TO LOOK AT IT
  Open index.html in a browser. Try the moon button top right:
  some palettes read better in dark mode than in light.

TO PUBLISH IT
  Replace the contents of your armontajab.github.io folder with
  these files. Keep the hidden .git folder. Then in GitHub Desktop
  write a summary, Commit to main, Push origin.

TO SWITCH LATER
  Copy style.css from another colour folder over the one in
  armontajab.github.io, then commit and push again.
